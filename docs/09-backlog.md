## После MVP

Реальные API жилья; рекламная монетизация; чат пользователей; верификация через вуз; интеграции с общежитиями; совместный бюджет и покупки; уборка; маршруты и время до вуза при наличии источника; другие города; мобильное приложение.

## Готовность задачи

Считаем задачу готовой, когда изменение работает по критериям приёмки, отражено в документации, прошло ревью и включено в общий сценарий. Для программной логики выполняются содержательные проверки. Название задачи и описание PR объясняют пользовательский результат.
